# Bank Management System (Data Structures PBL)
Open `index.html` to run. Deploy: push files to a GitHub repo → Settings → Pages → branch `main`, root.
Login: `admin` / `admin123` (frontend demo only, not real authentication).
Data lives in localStorage; Settings → Reset restores demo data. Money is stored in paise.
Data structures in `script.js`: Array (accounts), LinkedList (transactions), Stack (undo), Queue (service requests).
